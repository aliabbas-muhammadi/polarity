Here `pAUC` is the repository's **custom normalized low-FPR step metric**: recall is held at the
best empirically achievable operating point within each FPR step and integrated to the configured
limit. It is not conventional interpolated ROC partial AUC.

## Honest scope / remaining uncertainty

- **These are in-distribution numbers.** internal_test is drawn from the same PAWS-Wiki + CANNOT
  families as train (leakage-safe split, but same sources). The equivalent-negation positives come
  from the CANNOT family the model trained on. Strong in-distribution generalization is real and
  necessary, but it is **not** external-transfer evidence.
- Veritas later adds 75 author-created, protocol-held-out target-domain pairs. It is not an
  independently blinded/general benchmark. No Veritas data touched this training run.
- The validation→internal-test threshold gap (target ≤1% → 2.38% realized FPR) is direct evidence
  that a selection budget does not guarantee the same realized rate on another split.

## Subsequent evaluation

M6 applied the frozen model/protocol to Veritas and observed 31/31 recall with 2/44 false accepts
(4.55% realized FPR) at `tau=0.994833`, including 0/22 negation false accepts. The repository
