# M6.1 (part 2) — external MRPC transfer: weak result

MRPC is a second, externally sourced cross-dataset diagnostic. It tests whether the frozen Polarity
ranking and validation-selected thresholds carry from PAWS-Wiki+CANNOT/cache-query data to a
news-domain paraphrase corpus. They do not carry reliably. This negative result bounds the Veritas
observation and is part of the contribution.

## Source and provenance

- Corpus: Microsoft Research Paraphrase Corpus test split, 1,725 rows.
- Actual loader: `nyu-mll/glue`, configuration `mrpc`, split `test`, revision
  `bcdcba79d07bc864c1c254ccfcedcce55bcc9a8c`.
- Expected local source SHA-256:
  `7999ee0ba2af1c43e416c35d152bdcaa99acb79ae1791914e748535f78d8a18c`.
- Label mapping: paraphrase → `CACHE_EQUIVALENT`; not-paraphrase →
  `NOT_CACHE_EQUIVALENT`.
- Rows: 1,147 paraphrases and 578 non-paraphrases. All rows are retained. One normalized ordered
  pair duplicate is retained; no conflicting duplicate label was observed.

MRPC is a paraphrase corpus, not a cache-safety annotation set, so the mapping is informative but
not perfectly task-equivalent. The source revision, acquisition contract, checksums, label mapping,
and duplicate policy are committed in `reports/m6.1/mrpc-provenance.json`.

Raw MRPC text is ignored and not distributed. The public prediction artifact contains only stable
row identity/order, raw score, and calibrated score; it contains no gold label, pair type, or text.

## Threshold-free ranking

| metric on MRPC | value |
|---|--:|
| ROC-AUC | **0.639870** |
| repository step-pAUC over FPR `[0,0.02]` | **0.031938** |
| recall at actual FPR≤1% | 0.035745 |
| recall at actual FPR≤5% | 0.081081 |
| recall at actual FPR≤10% | 0.169137 |

The repository's pAUC is the normalized step integral of maximum achievable recall over the stated
FPR range. It is **not** scikit-learn's standardized partial AUC.

For correct context: M3.3's same-distribution internal-test threshold-free recall is 0.763 at actual
FPR≤1% and 0.968 at actual FPR≤5%. Veritas's separate descriptive sweep reaches 24/31 = 0.774 at
actual FPR≤1%; no Veritas pAUC equivalence is claimed.

## Score distributions and interpretation

Raw MRPC paraphrase scores have mean 0.9144 and median 0.9992; non-paraphrase scores have mean
0.7796 and median 0.9979. Both classes accumulate near the upper end of the score range. The
committed artifacts support observations of score saturation, calibration/location shift,
semantic overacceptance, and weak ranking (ROC-AUC 0.639870).

An author-run lexical-overlap audit reported that higher overlap worsens false acceptance, while
low-overlap negatives also fail; its non-paraphrase overlap mean/median was 0.415/0.391. The
procedure and overlap outputs are not committed, and the public MRPC gate does not recompute them,
so this is historical diagnostic evidence rather than a publicly reproducible metric. It does not
explain the result by itself. Neither MRPC nor the post-hoc probe proves that one data
characteristic caused the behavior or that one augmentation is the necessary remedy.

Author-run bag-of-words diagnostics reported source AUC 0.928 and label AUC 0.650, showing that
dataset-family or lexical shortcuts are possible confounders. The diagnostic procedure and outputs
are not committed, so these figures are historical evidence rather than publicly reproducible
metrics; they do not establish what features the trained model primarily used.

## Disposition and limits

**Weak external transfer to MRPC.** Polarity is not a general paraphrase detector, and its frozen
validation operating point does not preserve false-positive control on this corpus. This does not
erase the exact Veritas observations; it limits their interpretation to a small author-created
target-domain set.

Additional limitations:

- MRPC's label target differs from cache equivalence.
- One externally sourced corpus cannot characterize all deployment domains.
- The repository records author-run scoring with no threshold retuning, but “scored once” is not
  technically enforced or independently provable.
- The public score rows alone cannot reproduce any label-dependent metric.

## Reproduce honestly

The source-free public gate checks the score-only schema, sequential `row_index` values and row
count, the synthetic `mrpc-test-{row_index}` ID format, and the internal consistency of committed
report/provenance/binding hashes. It also cross-checks the committed protocol/model/bundle
fingerprints against one another. Without a local source, it does not authenticate those rows
against official MRPC rows or labels. Its success message explicitly says that metrics were
**not** reproduced:

```sh
uv run polarity transfer mrpc-report --check
```

Full metric reproduction requires an **already constructed** local JSON file matching the committed
byte checksum, schema, and row order:

```sh
uv run polarity transfer mrpc-report --check \
  --source data/raw/mrpc/mrpc-test-golden.json
```

The full gate joins labels only after source checksum/order verification, then recomputes row/class
counts, ROC-AUC, custom pAUC, frozen-threshold confusion matrices, score summaries, and duplicate
policy. The provenance manifest records the expected loader/revision and checksums, but the
repository does not currently provide a deterministic conversion procedure from Microsoft's
distribution or the named loader output to this exact JSON. A source-only clone must never describe
the first command as full MRPC reproduction.

## Banked hypothesis

No M7 training run is recommended now. MRPC and the authored probe are already development
signals. If this direction is reopened, preregistration, stopping rules, and a new independently
authored untouched final evaluation set must exist before data construction or scoring.
