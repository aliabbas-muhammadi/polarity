# M6.1 (part 1) — different-answer diagnostic probe

This is a **post-hoc, author-curated diagnostic**, not a benchmark or population-rate estimate. It
was created after inspection of the two Veritas false accepts to see where additional authored
examples landed under the already frozen validation-selected thresholds. It cannot establish a
cause, generalization rate, or necessary remedy.

## Method and dependence on Veritas

The probe contains 44 English question pairs in
`data/diagnostics/different-answer-probe.json`: 36 meaning-change negatives across six authored
categories (six each) and eight paraphrase controls. Two negative pairs copy Veritas examples
exactly, and eight probe rows share a Veritas sentence. The probe is therefore partly dependent on
the earlier target-domain material, not an independent evaluation set.

The repository records author-run scoring with the frozen `xp-006` checkpoint. It applies protocol
v2 operating points selected on validation; it does not select a threshold on the probe. Git does
not technically enforce the author's record that inference occurred only once.

## Observed counts

Meaning-change pairs accepted as equivalent at each validation-selected threshold:

| authored category | example | false accepts at `tau=0.994833` | false accepts at `tau=0.9996990000000001` |
|---|---|--:|--:|
| entity | France→Italy capital | **0/6** | 0/6 |
| comparative | larger→smaller, max→min | **0/6** | 0/6 |
| operation | add→remove, enable→disable | **0/6** | 0/6 |
| numeric | 15%→25%, 1945→1918 | **1/6** | 0/6 |
| temporal | yesterday→tomorrow, open→close | **2/6** | 0/6 |
| measurement | area→perimeter, radius→diameter, mean→median | **4/6** | 0/6 |
| paraphrase controls | France capital ≈ France's capital city | **8/8 recalled** | 8/8 |

`tau=0.994833` was selected on validation to target FPR≤1%; that budget is not a realized probe
FPR claim. The probe contains 36 authored negatives, of which 7 were accepted. At the strict
full-precision threshold selected for zero observed validation false positives, none of those 36
were accepted. All eight controls were accepted at both thresholds.

## Interpretation

Within this authored sample, false accepts concentrate in measurement (4), temporal (2), and
numeric (1) examples. That is a useful localization observation. It does not show that
measurement changes are the population's dominant failure mode, that lexical overlap caused the
errors, or that training-data augmentation is necessarily the right fix.

Each negative category has only six examples. Even 0/6 observed false accepts has a Wilson 95%
upper bound of roughly 39%, so zero counts should not be described as robust category performance.
The probe's construction after Veritas error inspection and its partial content reuse further
limit inference.

## Banked hypothesis

One possible future hypothesis is that independently sourced attribute-substitution negatives
could improve this slice. It is **not** recommended or executed as M7 here. Because the probe and
MRPC have already become development signals, any future experiment would first need a
pre-registered hypothesis, stopping rule, and independently authored untouched final evaluation
set. Veritas, this probe, and MRPC must not become that final set.

## Reproduce

```sh
uv run polarity transfer probe-report --check
```

The command rebuilds the committed report from the authored probe, score artifact, protocol, and
companion identity manifests. It performs no model inference and does not upgrade this diagnostic
into an independent benchmark.
